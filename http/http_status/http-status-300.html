300 Редиректы

300–399 статус коды — это редиректы. Они указывают, что для завершения запроса клиенту нужно предпринять дополнительные действия, обычно — перейти по другому URL.

  • 300 Multiple Choices

    За что отвечает:

    Запрос имеет несколько возможных ответов, клиент должен выбрать один из них.

    Когда используется:

    Например, когда ресурс доступен в нескольких форматах или языках.

  • 301 Moved Permanently

    За что отвечает:

    Ресурс был окончательно перемещён на новый URL.

    Когда используется:

    Для постоянного перенаправления; поисковые системы обновляют ссылки.

  • 302 Found

    За что отвечает:

    Ресурс временно доступен по другому URL, но в будущем может вернуться на исходный.

    Когда используется:

    Для временных перенаправлений.

  • 303 See Other

    За что отвечает:

    Ответ на запрос можно получить по другому URL, обычно с использованием GET.

    Когда используется:

    После успешного POST-запроса для перенаправления клиента на страницу результата.

  • 304 Not Modified

    За что отвечает:

    Ресурс не изменялся с момента последнего запроса, клиент может использовать кешированную версию.

    Когда используется:

    Для оптимизации трафика, когда ресурс не обновлялся.

  • 305 Use Proxy (устаревший)

    За что отвечает:

    Клиент должен использовать прокси, указанный в ответе.

    Когда используется:

    Практически не используется из-за проблем с безопасностью.

  • 306 (зарезервирован)

    За что отвечает:

    Этот код больше не используется.

  • 307 Temporary Redirect

    За что отвечает:

    Временный редирект, метод запроса не должен изменяться (например, POST остаётся POST).

    Когда используется:

    Для временных перенаправлений без изменения метода.

  • 308 Permanent Redirect

    За что отвечает:

    Постоянный редирект, метод запроса не должен изменяться.

    Когда используется:

    Для постоянных перенаправлений без изменения метода (альтернатива 301).
