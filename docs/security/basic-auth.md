# Basic Auth — простой способ авторизации
**Что такое Basic Auth?**

`Basic Auth `— это самый простой способ сказать серверу, кто ты, используя логин и пароль в одном HTTP-запросе.

**Как это работает?**

1. Клиент (например, браузер или приложение) берёт свой логин и пароль и кодирует их в специальный формат `Base64`.
Например, если логин ivan, а пароль secret, то строка будет:

```json
ivan:secret
```
После кодирования в `Base64` получится что-то вроде:
```json
aXZhbjpzZWNyZXQ=
```
2. Клиент отправляет запрос на сервер и добавляет в заголовок `Authorization` такую строку:
```json
    Authorization: Basic aXZhbjpzZWNyZXQ=
```
3. Сервер принимает этот заголовок, декодирует строку обратно, получает логин и пароль, и проверяет их в своей базе.
    Если всё правильно — даёт доступ, если нет — возвращает ошибку `401 Unauthorized`.

**Пример заголовка**:

```json
Authorization: Basic aXZhbjpzZWNyZXQ=
```

**Почему Basic Auth не очень безопасен?**

 - Логин и пароль передаются в каждом запросе (в закодированном, но не зашифрованном виде).

 - Если не использовать HTTPS, эти данные могут быть перехвачены злоумышленниками.

 - Обычно `Basic Auth` используют только вместе с защищённым соединением (HTTPS).

**💡 Аналогия с рестораном:**
`Basic Auth` — это как при входе в ресторан сразу назвать охраннику свои имя и пароль каждый раз, когда заходишь. Если у тебя есть пропуск (токен), заходить проще и безопаснее.


# Пример использования Basic Auth
**Клиент: Отправка запроса с Basic Auth**

Допустим, у тебя есть логин `ivan` и пароль `secret`. Клиент кодирует строку `ivan:secret` в `Base64` и отправляет запрос с заголовком:

```json
GET /api/user/profile HTTP/1.1
Host: api.example.com
Authorization: Basic aXZhbjpzZWNyZXQ=
Accept: application/json
```
**Сервер: Проверка Basic Auth**

Когда сервер получает запрос с таким заголовком, он:

 - Извлекает значение из заголовка `Authorization`.

 - Убирает префикс `Basic` и декодирует Base64, получая логин и пароль.

 - Сравнивает их с базой пользователей.

 - Если данные верны — даёт доступ, иначе — ответ с кодом `401 Unauthorized`.
