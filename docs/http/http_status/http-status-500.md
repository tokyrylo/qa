# 500 Ошибки сервера

**500–599 статус коды**— это ошибки сервера. Они означают, что запрос клиента был получен и понят, но сервер не смог его корректно обработать из-за внутренних проблем.


 - **500 Internal Server Error**

    **За что отвечает:**

    Общая ошибка сервера — что-то пошло не так, но сервер не может уточнить причину.

    **Когда используется:**

    При неожиданных исключениях и сбоях.

 - **501 Not Implemented**

    **За что отвечает:**

    Сервер не поддерживает функциональность, необходимую для обработки запроса.

    **Когда используется:**

    Если метод или функционал не реализован.

 - **502 Bad Gateway**

    **За что отвечает:**

    Сервер, выступающий как шлюз или прокси, получил неправильный ответ от вышестоящего сервера.

    **Когда используется:**

    При проблемах с обратным прокси, балансировщиками.

 - **503 Service Unavailable**

    **За что отвечает:**

    Сервис временно недоступен (перегрузка, техобслуживание).

    **Когда используется:**

    Когда сервер не может обработать запрос сейчас, но ожидается восстановление.

 - **504 Gateway Timeout**

    **За что отвечает:**

    Шлюз или прокси не дождался ответа от вышестоящего сервера.

    **Когда используется:**

    При таймаутах при запросах к другим сервисам.

 - **505 HTTP Version Not Supported**

    **За что отвечает:**

    Сервер не поддерживает версию протокола HTTP, указанную в запросе.

    **Когда используется:**

    Если клиент использует устаревшую или неподдерживаемую версию HTTP.

 - **506 Variant Also Negotiates**

    **За что отвечает:**

    Ошибка конфигурации сервера, когда вариант содержимого вызывает бесконечный цикл.

    **Когда используется:**

    Очень редкий статус, связанный с содержимым-negotiation.

 - **507 Insufficient Storage (WebDAV)**

    **За что отвечает:**

    Сервер не может сохранить данные из-за недостатка места.

    **Когда используется:**

    В расширении WebDAV.

 - **508 Loop Detected (WebDAV)**

    **За что отвечает:**

    Обнаружена бесконечная петля при обработке запроса.

    **Когда используется:**

    В WebDAV при циклических ссылках.

 - **510 Not Extended**

    **За что отвечает:**

    Запрос не выполнен, потому что не выполнены расширения протокола.

    **Когда используется:**

    Для расширенных возможностей протокола.

 - **511 Network Authentication Required**

    **За что отвечает:**

    Требуется аутентификация в сети (например, Wi-Fi портал).

    **Когда используется:**

    Для ограничения доступа к сети.
