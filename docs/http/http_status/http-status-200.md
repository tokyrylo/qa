# 200 Успешные ответы
**200–299 статус коды** — это успешные ответы. Они означают, что запрос клиента был успешно получен, понят и обработан сервером.

- **200 OK**

    **За что отвечает**:

    Запрос выполнен успешно, и сервер возвращает запрашиваемые данные (например, HTML-страницу, JSON, файл).

    **Когда используется**:

    Для успешных GET, POST, PUT и других запросов, когда всё прошло без ошибок.

- **201 Created**

    **За что отвечает**:

    Ресурс был успешно создан на сервере.

    **Когда используется**:

    После успешного POST-запроса, когда создаётся новая сущность (например, новая запись в базе).

 - **202 Accepted**

    **За что отвечает**:

    Запрос принят, но обработка ещё не завершена.

    **Когда используется**:

    Когда сервер асинхронно обрабатывает запрос и не может сразу дать результат.

 - **203 Non-Authoritative Information**

    **За что отвечает**:

    Сервер успешно обработал запрос, но возвращает данные, полученные из внешнего источника, а не оригинальные с сервера.

    **Когда используется**:

    Редко применяется, например, в прокси-серверах.

 - **204 No Content**

    **За что отвечает:**

    Запрос выполнен успешно, но тело ответа отсутствует.

    **Когда используется:**

    Например, после успешного DELETE-запроса или если нет данных для возврата.

 - **205 Reset Content**

    **За что отвечает:**

    Запрос выполнен успешно, и клиент должен сбросить представление (например, очистить форму).

    **Когда используется:**

    В интерфейсах, где требуется сбросить состояние после запроса.

 - **206 Partial Content**

    **За что отвечает:**

    Сервер возвращает часть запрашиваемого ресурса, согласно заголовку Range.

    **Когда используется:**

    Для дозагрузки файлов, просмотра видео частями и т.п.

- **207 Multi-Status (WebDAV)**

    **За что отвечает:**

    Содержит несколько статусных кодов для разных операций в одном ответе.

    **Когда используется:**

    В расширении WebDAV для множественных операций.

 - **208 Already Reported (WebDAV)**

    **За что отвечает:**

    Информирует, что уже были перечислены ресурсы в предыдущем ответе.

    **Когда используется:**

    Оптимизация в WebDAV.

- **226 IM Used**

    **За что отвечает:**

    Сервер выполнил запрос с использованием Delta encoding.

    **Когда используется:**

    Для оптимизации передачи изменений.
