# Как делать запросы к API — инструменты

`API` — это интерфейс для общения программ и приложений. Чтобы с ним работать, нужно уметь отправлять запросы и получать ответы. Для этого используют специальные инструменты.
Популярные инструменты для работы с API

1. **Postman**:

    - Графический инструмент с удобным интерфейсом.

    - Позволяет создавать и отправлять запросы разных типов (`GET`, `POST`, `PUT` и др.).

    - Можно сохранять запросы, группировать их, создавать сценарии тестирования.

    - Подходит и новичкам, и опытным тестировщикам.

    **Пример:**

    - Вводишь URL и метод запроса.

    - Добавляешь заголовки и тело (если нужно).

    - Нажимаешь кнопку «Send» и смотришь ответ сервера.

2. **curl**:

    - Утилита командной строки для отправки HTTP-запросов.

    - Очень мощная и гибкая, работает в терминале Linux, macOS и Windows (через WSL или PowerShell).

    - Подходит для быстрого тестирования и автоматизации.

**Пример команды**:

```json
curl -X GET https://api.example.com/users/123
```
3. **Insomnia**:

    - Ещё один удобный графический клиент для API.

    - Похож на Postman, но с другим интерфейсом.

    - Поддерживает REST, GraphQL и другие типы API.

    - Есть возможности для создания переменных и сценариев.
