📚 Энциклопедия по HTTP и API

Добро пожаловать в Энциклопедию по HTTP, API и авторизации — сборник материалов для тестировщиков и всех, кто хочет глубже понять, как работают интернет-запросы.

🚀 Что вы найдёте внутри

  • HTTP — основы протокола, методы, заголовки, коды ответов.
  • API — типы API, структура запросов и ответов, работа с параметрами, форматы данных.
  • Безопасность — авторизация, токены, Basic Auth, Bearer Token, JWT, OAuth 2.0.
  • Практика — работа с Postman, Insomnia, curl, Swagger.
  • QA-подход — тестирование API, чек-листы, поиск типичных ошибок.

🛠 Рекомендуемые инструменты

  • Postman — для тестирования API.
  • Insomnia — альтернатива Postman.
  • Swagger — для документации и тестирования.
  • curl — тесты прямо из командной строки.

📌 Как пользоваться энциклопедией

  1. Начните с раздела HTTP, чтобы понять основы.
  2. Перейдите к API, чтобы научиться работать с запросами и ответами.
  3. Изучите Безопасность, чтобы разбираться в токенах и авторизации.
  4. Примените знания в Практике с Postman и Swagger.
  5. Используйте QA-раздел для тестирования и поиска багов.
