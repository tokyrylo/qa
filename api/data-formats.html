Форматы данных в API

Когда клиент (например, браузер или мобильное приложение) общается с сервером через API, они обмениваются данными. Эти данные должны быть в определённом формате, чтобы обе стороны понимали друг друга. Основные форматы данных

  1. JSON (JavaScript Object Notation):

    • Самый популярный формат для обмена данными в API.

    • Похож на простой текст, который легко читать и писать человеку и компьютеру.

    • Использует структуру ключ-значение (словари и списки).

    • Поддерживается почти во всех языках программирования.

    Пример JSON:

{
  "name": "Иван",
  "age": 30,
  "languages": ["Русский", "Английский"]
}

  1. XML (eXtensible Markup Language):

    • Старый формат, который выглядит как набор тегов (похож на HTML).

    • Читается и пишется сложнее, чем JSON.

    • Часто используется в SOAP API и старых системах.

    Пример XML:

<Person>
  <Name>Иван</Name>
  <Age>30</Age>
  <Languages>
    <Language>Русский</Language>
    <Language>Английский</Language>
  </Languages>
</Person>

  1. Form Data (application/x-www-form-urlencoded):

    • Формат, который похож на строку с парами "ключ=значение", разделёнными амперсандом (&).

    • Часто используется для отправки данных из HTML-форм.

    • Менее удобен для сложных структур.

    Пример:

name=Ivan&age=30&languages=Russian&languages=English

  1. Multipart/Form-Data:

    • Используется, когда нужно отправить файлы вместе с данными (например, фото или документы).

    • Разделяет данные на части с заголовками, чтобы сервер понимал, где файл, а где обычные данные.

Почему это важно знать QA?

  • Чтобы правильно читать и проверять запросы и ответы API.

  • Чтобы понимать, как сервер обрабатывает данные и что ожидать в ответе.

  • Для написания тестов и автоматизации, особенно при проверке форматов и структуры данных.

Как узнать формат данных?

В HTTP-запросах и ответах формат указывается в заголовке Content-Type, например:

  • application/json — JSON

  • application/xml — XML

  • application/x-www-form-urlencoded — форма

  • multipart/form-data — файлы и форма
