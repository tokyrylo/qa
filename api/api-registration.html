📝 Регистрация пользователя через API

Рассмотрим, как отправить запрос на регистрацию нового пользователя тремя способами: Postman,

🚀 Регистрация в Postman

1. Открой Postman и создайте новый запрос.

  1. В поле метода выбери POST.

3. Введи URL, например:

http://localhost:8000/api/v1/register (*)

4. Перейди во вкладку Headers и добавь:

Content-Type: application/json

  1. Перейди во вкладку Body, выбери raw и формат JSON.

  2. Вставь тело запроса:

{
  "email": "user10@example.com",
  "username": "test_user",
  "password": "Qq!123456",
  "name": "string"
}

  1. Нажми Send — внизу появится ответ от сервера

Регистрация в Insomnia

  1. Создай новый запрос (New Request).

  2. Выбери метод POST и укажи URL:

http://localhost:8000/api/v1/register (*)

  1. Во вкладке Body выбери JSON.

  2. Вставь:

{
  "email": "user11@example.com",
  "username": "test_user",
  "password": "Qq!123456",
  "name": "string"
}

  1. Нажми Send и проверь ответ.

Регистрация в Swagger UI

  1. Перейди на страницу Swagger-документации API (например, http://localhost:8000/api/v1/register).

  2. Найди эндпоинт POST /api/v1/register.

  3. Нажми Try it out.

  4. Заполни поля:

  5. "email": "user12@example.com"

  6. "username": "test2_user"
  7. "password": "Qq!123456"
  8. "name": "string"

Нажми Execute — Swagger покажет и отправленный запрос, и ответ от сервера.

Если при регистрации возвращается ошибка 400 Bad Request, проверь:

  • правильность формата JSON (кавычки, запятые);

  • обязательные поля;

  • уникальность email.
