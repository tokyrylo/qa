🤖 Инструменты для автоматизации тестов API

Автоматизация тестирования позволяет быстро проверять корректность работы API, повторять тесты и интегрировать проверки в CI/CD.

1. Postman (Collection Runner + Newman)

  • Позволяет создавать коллекции запросов API и запускать их автоматически.
  • Можно добавлять тестовые скрипты на JavaScript для проверки ответов.
  • Newman — CLI-инструмент для запуска коллекций Postman в терминале или CI/CD.

Пример теста в Postman:

pm.test("Проверка кода ответа", function () {
    pm.response.to.have.status(200);
});

pm.test("Проверка структуры JSON", function () {
    var jsonData = pm.response.json();
    pm.expect(jsonData).to.have.property("id");
    pm.expect(jsonData).to.have.property("email");
});

Запуск коллекции через Newman:

newman run my_collection.json -e my_environment.json

2. Insomnia (Insomnia Designer + CLI)

  • Позволяет создавать API-запросы и писать тестовые сценарии.

  • Insomnia Designer поддерживает OpenAPI спецификации, можно генерировать тесты на их основе.

3. REST-assured (Java)

  • Фреймворк для автоматизации тестов REST API на Java.

  • Подходит для QA и интеграционных тестов.

  • Пример проверки статуса и тела ответа:

given()
    .header("Authorization", "Bearer <token>")
.when()
    .get("/api/v1/users/1")
.then()
    .statusCode(200)
    .body("username", equalTo("ivan"));

4. Pytest + Requests (Python)

  • Позволяет писать тесты API на Python.
  • Можно проверять ответы, заголовки, коды статусов и содержимое JSON.

Пример:

import requests

def test_get_user():
    response = requests.get(
        "https://api.example.com/api/v1/users/1",
        headers={"Authorization": "Bearer <token>"}
    )
    assert response.status_code == 200
    data = response.json()
    assert data["username"] == "ivan"

6. CI/CD интеграция

  • Запуск тестов автоматически при каждом деплое.

  • Используем GitHub Actions, GitLab CI, Jenkins или других CI-серверы.

  • QA может настроить отчёты о пройденных и упавших тестах.

✅ Рекомендации QA

  1. Используй GUI-инструменты (Postman, Insomnia) для быстрых проверок и создания тестов.
  2. Для повторяемых сценариев лучше использовать кодовые фреймворки (Pytest, REST-assured, Karate).
  3. Интегрируй тесты в CI/CD, чтобы сразу видеть регрессии и ошибки.
  4. Создавай коллекции и окружения, чтобы легко менять Base URL, токены и другие параметры.
  5. Сохраняй результаты прогонов и используй их для сравнения с предыдущими тестами.
