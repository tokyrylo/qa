🛠 Diff-инструменты для QA

Diff-инструменты позволяют сравнивать файлы, ответы API или результаты тестов, чтобы видеть, что изменилось. Они очень полезны для QA, когда нужно проверять:

  • изменения в JSON-ответах API после обновлений сервера,
  • корректность данных после миграций,
  • разницу между тестовыми и реальными данными.

1. Для чего нужны

  • Сравнение старого и нового ответа API;
  • Поиск непредвиденных изменений в данных;
  • Проверка консистентности при деплое или обновлениях.

2. Примеры инструментов

Инструмент Описание Особенности
Meld GUI для Linux/Windows/Mac Сравнивает файлы и каталоги, подсвечивает изменения
DiffMerge Кроссплатформенный GUI Поддержка 3-стороннего сравнения, визуальная подсветка
Beyond Compare Платный GUI Сравнение файлов, папок, изображений, текстов
diff (CLI) Командная строка в Linux/macOS Быстрое сравнение текстовых файлов
git diff CLI для Git Сравнение изменений в коде и JSON-файлах

3. Как использовать для API

  1. Сохрани старый ответ API в файл:
curl -s https://api.example.com/users/1 > old_response.json
  1. Получи новый ответ после изменений:
curl -s https://api.example.com/users/1 > new_response.json
  1. Сравни с помощью CLI:
diff old_response.json new_response.json
  1. В GUI-инструменте (например, Meld) открой оба файла — изменения будут подсвечены цветом.

4. Практические советы для QA

  • Используй форматирование JSON (jq . old_response.json) перед сравнением, чтобы строки были структурированы.

  • Для больших данных лучше применять 3-way diff, чтобы видеть изменения между ветками или версиями.

  • Интегрируй diff-проверку в CI/CD, чтобы автоматические тесты фиксировали непредвиденные изменения.
